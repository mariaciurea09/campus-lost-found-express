# campus-lost-found-express
Sistem digital destinat mediului universitar închis. Procesul este optimizat pentru simplitate și eficiență: când un student sau un cadru didactic găsește un obiect, îl înregistrează specificând locația exactă de preluare. Persoana care a pierdut obiectul îl caută în interfață și, după ce îl ridică din locul menționat, îl marchează ca Recuperat.
